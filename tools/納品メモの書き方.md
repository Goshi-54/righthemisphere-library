# 納品メモの書き方

素材ライブラリに素材を渡すときは、素材のファイルと一緒に「納品メモ」（CSV）を付けます。受け取った側は `tools/assets.py receive` でこのメモを読み、素材をいったん「保留」に置きます。本人が採否を決めてから、正式な素材として足します。

## 置き方

- 1回の納品につき、フォルダを1つ作ります。中に素材のファイルと `納品メモ.csv` を置きます。
- 文字コードは UTF-8 です。1行目は列の名前にします。
- 1行に素材1点を書きます。

## 列

| 列 | 要る？ | 中身 |
|---|---|---|
| 名前 | 要る | 素材の名前。日本語で、何をしているかが分かる短い名前（例：手を振って声をかける） |
| ファイル | 要る | 納品メモから見た、素材のファイルの場所（例：gif/手を振る.gif）。ファイル名は日本語でよい |
| 種類 | 要る | 口パク／全身の動き／掛け合い／等身大／マイクラ／背景／アイコン／音声／その他 のどれか |
| コマのフォルダ | 任意 | GIFや動画のもとになったコマのPNGを入れたフォルダ（例：koma/手を振る） |
| メモ | 任意 | 作った理由、どの台本のどこで使うか、気をつけることなど |

## 例

```csv
名前,ファイル,種類,コマのフォルダ,メモ
手を振って声をかける,gif/手を振る.gif,全身の動き,koma/手を振る,台本03の冒頭で使う
驚いて口を丸く開く,gif/驚く.gif,口パク,,
```

## 受け取ったあと

1. `receive`：ドライブの `<キャラ>/90_保留/<日付>_<依頼>/` に写し、ライブラリの「保留」タブに見本を出す。履歴に「受け取り」の行が入る。
2. `decide`：本人の採否（採用／仮置き／直し／見送り）と、本人の言葉の原文を記録する。履歴に「採否」の行が入る。
3. `promote`：採用・仮置きの素材を正式な場所に移す。履歴に「追加」の行が入る。今はアイコンだけで、ほかの種類は最初に実際に足すときに作る。
4. ライブラリの元フォルダで `add_download_ids.py` と `build_public.py` を流し、このフォルダで `make_top.py` を流してから公開する。

Chatworkの依頼で作った素材も、同じように保留に置きます（本人の方針：ライブラリへの追加は保留データとして残す）。
